# Production asset sources

FreshDedicatedStorage embeds two geometry files used by the released mod. Both source assets are by Quaternius and are licensed CC0 1.0 Universal.

| File | In-game use | Source |
| --- | --- | --- |
| `dedicated_storage_box.obj` | Dedicated Storage Box | https://poly.pizza/m/YyAS0OHd4i |
| `hugins_reliquary_column.obj` | Hugin's Reliquary | https://poly.pizza/m/n8ZvVFcJhl |

The original textures are not redistributed. FreshDedicatedStorage creates its material colors at runtime. The included `QUATERNIUS-LICENSE.txt` records the CC0 license information.
