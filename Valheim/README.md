# Valheim Mods

Public production source for Valheim mods by JuStIIFrEsH.

## FreshCommands

Console and chat commands for corpse recovery, teleporting home or to corpses, and persistent named teleport locations.

- [Source](./FreshCommands)
- [Thunderstore](https://thunderstore.io/c/valheim/p/JuStIIFrEsH/FreshCommands/)

## FreshDedicatedStorage

Stackable single-item dedicated storage with large capacity and Hugin's Reliquary for routing matching inventory items to assigned boxes.

- [Source](./FreshDedicatedStorage)
- [Thunderstore](https://thunderstore.io/c/valheim/p/JuStIIFrEsH/FreshDedicatedStorage/)

## Building

The projects reference assemblies from an installed Valheim and Thunderstore profile. Set `VALHEIM_PATH` and `VALHEIM_PROFILE_PATH`, or pass `-ValheimPath` and `-ProfilePath` to the PowerShell build scripts.

Current release packages used by the publishing workflows are stored under `production/`.
